      Solution

      class Solution {
    public int[] twoSum(int[] nums, int target) {
        // Create a hash map to store the difference between the target and each number, along with its index
        Map<Integer, Integer> map = new HashMap<>();

        // Iterate through the array
        for (int i = 0; i < nums.length; i++) {
            // Calculate the difference
            int complement = target - nums[i];

            // If the complement is in the map, return the indices
            if (map.containsKey(complement)) {
                return new int[] { map.get(complement), i };
            }

            // Otherwise, put the current number and its index in the map
            map.put(nums[i], i);
        }

        // Since the problem guarantees one solution, this line will never be reached
        throw new IllegalArgumentException("No two sum solution");
    }
}

      Approach Name: Two-pass Hash Table

      Intuition: By using a hash map, we can store the difference between the target and each number, along with its index. This allows us to check if the complement (the number needed to reach the target) exists in the map in constant time.

      Algorithm:

      1. Initialize a hash map to store the difference between the target and each number, along with its index.
      2. Iterate through the array.
      3. For each number, calculate the complement (target - number).
      4. Check if the complement exists in the map.
      5. If it does, return the indices of the complement and the current number.
      6. If it does not, add the current number and its index to the map.

      Complexity Analysis:

      • Time Complexity: O(n), where n is the number of elements in the array. We traverse the array once.
      • Space Complexity: O(n), the space used by the hash map.
